# MOHSEN - LOGO! Soft Comfort PLC Simulator

اپلیکیشن اندروید شبیه‌ساز PLC مشابه Siemens LOGO! Soft Comfort.

## نحوه ساخت APK در گیت‌هاب
1. فایل‌های داخل این آرشیو را در ریشه مخزن گیت‌هاب خود قرار دهید.
2. وارد تب **Actions** شوید و منتظر بمانید ورک‌فلو **Build MOHSEN APK** کامل شود.
3. از بخش **Artifacts** فایل `MOHSEN-APK` را دانلود کنید.
